# challenge19-JATE

## Description

JATE (Just Another Text Editor) is a Progressive Web Application (PWA) that runs in the browser and functions offline. This text editor features data persistence techniques using IndexedDB for redundancy and can be installed locally on your device.

## Features

- Progressive Web Application (PWA)
- Works offline
- IndexedDB for data persistence
- Install locally as a desktop application
- Syntax highlighting for JavaScript
- Auto-save functionality
- Service Worker for caching static assets

## Installation

1. Clone the repository:
   ```bash
   git clone git@github.com:JoseGuache/challenge19-JATE.git
   ```
2. Navigate to the project directory
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage

1. Start the application:
   ```bash
   npm run start
   ```
2. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
3. To install the application locally:
   - Click the "Install" button in the application
   - Or use the install icon in your browser's address bar

## Technologies Used

- JavaScript
- Webpack
- IndexedDB
- Service Workers
- Express.js
- Node.js
- Workbox
- CodeMirror (for text editor functionality)
